# Personal Expense Tracker

A desktop expense tracking application built with Python and Tkinter.

## Features

- Add expenses
- Delete expenses
- Search by category
- Search by date
- Search by minimum amount
- Calculate total expenses
- Save data in JSON
- Load saved expenses
- Input validation
- Graphical User Interface

## Technologies

- Python
- Tkinter
- JSON

## Project Structure

main.py       → GUI
tracker.py    → Expense logic
Expenses.json → Data storage

## How to Run

python main2.py
